# Changelog

This file summarizes the features and configuration of each Clear F3 version.

## 1.0.0

### Features

#### Debug overlay

- Introduces a grouped F3 overlay inspired by Minecraft 26.4.
- Aligns row labels and values, wraps long content, and supports continuation lines.
- Keeps panel widths stable during ordinary value changes and shortens eligible tag lists when space is limited.
- Uses a fixed overlay scale equivalent to GUI Scale 2 while preserving the applicable vanilla debug options, restrictions, and charts.
- Supports switching between Clear F3 and vanilla F3 with F8; F3 continues to show or hide the debug screen.

#### Customization

- Adds General and Row colors settings pages with collapsible groups and scrolling.
- Allows independent Key Color and Value Color settings for each debug row.
- Provides 16 color presets, RGB/ARGB hex input, and a preview before applying a change.

#### Platforms and builds

- Runs on the client in singleplayer and multiplayer.
- Includes 14 Fabric build targets from 1.20.1 through 26.3, plus NeoForge 26.3.

## 1.0.0

### 功能

#### 调试界面

- 提供参考 Minecraft 26.4 设计的分组式 F3 界面。

#### 自定义配置

- 增加“常规”和“条目颜色”设置页，支持分组折叠与滚动浏览。
- 每条 DebugRow 可分别设置 Key Color 与 Value Color。
- 提供 16 种预设颜色、RGB/ARGB 十六进制输入，以及应用前预览。

#### 平台与构建

- 仅在客户端运行，可用于单人游戏和多人服务器。
- 提供从 1.20.1 到 26.3 的 14 个 Fabric 构建目标，以及 NeoForge 26.3。
